# بهینه‌سازی سرعت لحظه‌ای قیمت‌ها و تعمیر کامل نمودارهای تاریخی از API

این طرح، مشکل توقف رمزارزها هنگام بارگذاری اولیه و خطای «نمودار در دسترس نیست» را به صورت ریشه‌ای برطرف می‌کند؛ به گونه‌ای که هم قیمت‌های لحظه‌ای و هم نمودارها مستقیماً از API صرافی‌ها و آرشیوها تغذیه شوند و **مصرف دیتابیس (Cloudflare D1) برای قیمت‌ها و نمودارها دقیقاً صفر** باقی بماند.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> بر اساس پاسخ شما و بررسی دقیق کدهای فعلی، تصمیمات کلیدی زیر در این طرح لحاظ شده‌اند:

- **تصمیم تاییدشده ۱ (استقلال کامل وب‌سوکت و قیمت‌های داخلی)**: قفل `initialPricesLoaded` که باعث می‌شد وب‌سوکت رمزارزها منتظر پاسخ سرور بماند کاملاً حذف می‌شود. در همان میلی‌ثانیه اول ورود، وب‌سوکت بایننس و درخواست `/api/prices` به صورت موازی و مستقل اجرا می‌شوند؛ هر کدام زودتر برسد فوراً روی صفحه می‌نشیند.
- **تصمیم ۲ (دریافت مستقیم نمودارها از API بدون رد کردن کندل‌های معتبر)**: صرافی‌ها (KuCoin, OKX, Gate, Wallex) و آرشیو بازار ایران (`iran-market` و `nerkhsanj`) خودشان تاریخچه کامل کندل‌ها را در API برمی‌گردانند. علت خطای «در دسترس نیست» این بود که تابع `validateHistoryPoints` در بک‌اند و فرانت‌اند با قوانین بیش‌ازحد سخت‌گیرانه (مثل رد کردن کل نمودار در صورت تعطیلی آخر هفته بازار ایران یا اختلاف جزئی قیمت لحظه‌ای با آخرین کندل بسته شده) داده‌های سالم API را دور می‌ریخت. با اصلاح این اعتبارسنجی و افزودن اتصال خودکار نقطه آخر به قیمت لحظه‌ای، تمام نمودارها در همه بازه‌ها (`1H`, `1D`, `3D`, `1W`, `1M`, `1Y`) مستقیماً از API رسم می‌شوند.

---

## 1. Overview & Core Concept

- **What It Does**:
  1. **آپدیت آنی و بدون توقف رمزارزها**: اتصال فوری به استریم زنده رمزارزها در لحظه باز شدن برنامه، بدون وابستگی به زمان پاسخ‌دهی نرخ‌های داخلی.
  2. **تغذیه ۱۰۰٪ مستقیم نمودارها از API تاریخی**: واکشی مستقیم تاریخچه کندل‌ها (OHLC / Klines) از API صرافی‌های جهانی، والکس (برای تتر) و آرشیو رسمی بازار داخلی، همراه با کش لبه (Edge Cache) برای سرعت بالا و مصرف صفر دیتابیس.
- **Target Audience / Persona**: کاربران رصد لحظه‌ای بازار طلا، سکه، ارز، تتر و رمزارزها که نیاز به مشاهده آنی قیمت‌ها و نمودارهای دقیق در تمامی تایم‌فریم‌ها دارند.
- **Key Value**: حذف کامل تأخیر اولیه، رفع خطای «نمودار در دسترس نیست» در کارت‌ها و پنجره جزئیات، و تضمین عدم پر شدن دیتابیس D1.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **ورود به برنامه**: به محض باز شدن صفحه، کش محلی نمایش داده می‌شود و هم‌زمان در میلی‌ثانیه صفر، وب‌سوکت رمزارزها (`connectPrices`) و دریافت نرخ‌های روز (`loadPrices`) مستقلاً شروع به کار می‌کنند. تیک‌های زنده رمزارزها بلافاصله تپش پیدا می‌کنند و نرخ‌های داخلی نیز به محض دریافت روی کارت‌ها می‌نشینند.
  2. **مشاهده اسپارک‌لاین‌ها (نمودارهای کوچک روی کارت‌ها)**: کارت‌های داشبورد و بازار بدون خطای خالی ماندن، روند ۲۴ ساعته یا هفتگی دارایی را به صورت خطی نرم (`tabular-nums` برای اعداد) نمایش می‌دهند.
  3. **پنجره جزئیات و تغییر بازه زمانی (`1H` تا `1Y`)**: با کلیک روی هر دارایی (طلا ۱۸ عیار، سکه، دلار، تتر، بیت‌کوین و...)، نمودار بلافاصله از API تاریخچه دریافت و رسم می‌شود. آخرین نقطه نمودار همیشه به قیمت زنده فعلی متصل می‌شود تا نمودار کاملاً به‌روز باشد.
- **Visual Identity & Theme**:
  - حفظ کامل هویت بصری فعلی دارایی (پشتیبانی از تم روشن و تاریک، اعداد فارسی تراز شده با `tabular-nums`، رنگ سبز `#16865b` برای روند صعودی و قرمز `#d84b55` برای روند نزولی).
- **Interactive Feedback & Motion**:
  - نمایش آنی تغییرات قیمت روی کارت‌ها در فریم‌های انیمیشن (`requestAnimationFrame`) بدون پرش صفحه.
  - جابجایی نرم بین بازه‌های زمانی نمودار (`۱ ساعت`، `۲۴ ساعت`، `۳ روز`، `۱ هفته`، `۱ ماه`، `۱ سال`) با کش حافظه و Edge Cache.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: اجرای موازی و بدون قفل (Non-Blocking Live Stream)**
  - *Chosen Approach*: فراخوانی هم‌زمان `connectPrices()` و `loadPrices()` در لحظه راه‌اندازی و حذف شرط توقف وب‌سوکت.
  - *Why*: وب‌سوکت رمزارزها در کمتر از ۲۰۰ میلی‌ثانیه متصل می‌شود؛ نگه داشتن آن پشت درخواست HTTP نرخ‌های داخلی باعث می‌شد کاربر حس کند رمزارزها متوقف شده‌اند.
  - *Alternatives Considered*: صبر کردن تا دریافت هم‌زمان همه منابع که به دلیل نوسان پینگ سرویس‌های داخلی، سرعت نمایش رمزارزها را کاهش می‌داد.

- **Decision 2: استراتژی نمودارها بر پایه API صرافی‌ها و آرشیو (Zero-DB Chart Engine)**
  - *Chosen Approach*: استفاده مستقیم از API کندل‌های تاریخی صرافی‌ها (KuCoin, OKX, Gate.io برای رمزارزها، Wallex و Nobitex/Iran-Market برای تتر، و Iran-Market / Nerkhsanj برای طلا، سکه و ارز) به همراه اصلاح تابع پالایش نقاط (`validateHistoryPoints` و `validateClientHistory`).
  - *Why*:
    1. صرافی‌ها و سرویس‌های آرشیو خودشان داده‌های تاریخی دقیق را نگه می‌دارند و نیازی به ذخیره ثانیه‌ای یا دقیقه‌ای در دیتابیس D1 ما نیست (مصرف دیتابیس = صفر).
    2. در کد قبلی، اگر بازار طلا و ارز در روزهای پنجشنبه/جمعه یا تعطیلات رسمی کندل جدید ثبت نکرده بود، یا اگر بین آخرین کندل آرشیو و قیمت لحظه‌ای کمی فاصله زمانی وجود داشت، تابع اعتبارسنجی کل نمودار را پاک می‌کرد و پیام «در دسترس نیست» نشان می‌داد! با اصلاح منطق اعتبارسنجی، داده‌های واقعی API بدون حذف شدن نمایش داده می‌شوند و نقطه پایانی به نرخ لحظه‌ای وصل می‌گردد.

### Data Model & State
- **Live Prices State**:
  - ذخیره‌سازی در حافظه رم سرور (`inMemoryPrices`) و کش لبه کلودفلر (`caches.default`) به همراه کش محلی مرورگر (`localStorage`) برای بارگذاری آنی.
- **Chart History Pipeline**:
  - **رمزارزها (`crypto`)**: دریافت کندل‌های استاندارد از صرافی‌های KuCoin، OKX و Gate.io؛ پالایش نقاط معتبر و اتصال نقطه آخر به قیمت زنده دارایی.
  - **تتر (`usdt`)**: دریافت کندل‌های واقعی تومان از Wallex UDF API (`USDTTMN`) برای تمام بازه‌ها (`1H` تا `1Y`)، و در صورت عدم پاسخ‌دهی، استفاده خودکار از آرشیو `USDT_IRR` و ساخت روند روزانه بر اساس قیمت باز شدن و تغییر ۲۴ ساعته.
  - **طلا، سکه و ارزهای داخلی (`domestic`)**: دریافت رکوردهای تاریخی OHLC از آرشیو `iran-market` و پشتیبان `nerkhsanj`. برای بازه‌های کوتاه‌مدت (`1H` و `1D`)، ترکیب نقاط بازگشایی، کف/سقف روزانه، تیک‌های ثبت‌شده در حافظه و قیمت زنده فعلی تا نمودار روزانه و ساعتی همیشه فعال و دقیق باشد.

### Interactive Component & State Mapping
- **راه‌اندازی اولیه (`Boot Sequence`)**:
  - اجرای بلافاصله `connectPrices()` و `loadPrices()` به صورت مستقل و موازی.
  - حذف گیت مسدودکننده در `ws.onmessage` تا هر تیک دریافتی از وب‌سوکت بلافاصله کارت مربوطه را به‌روز کند.
- **موتور اعتبارسنجی تاریخچه (`validateHistoryPoints` & `validateClientHistory`)**:
  - حذف شروطی که به خاطر تعطیلات بازار یا فاصله زمانی بین کندل‌ها کل آرایه نقاط را خالی (`[]`) برمی‌گرداندند.
  - مرتب‌سازی زمانی، حذف نقاط تکراری یا صفر، فیلتر کردن نوسانات پرت (Outliers)، و افزودن نقطه قیمت لحظه‌ای (`withCurrent`) در انتهای نمودار بدون رد کردن کل تاریخچه در صورت تغییر قیمت روزانه.
