# دارایی من (Darayi)

Persian portfolio / price tracker (PWA) on a **free** Cloudflare Worker + D1.

- **Start here:** [`HANDOFF.md`](HANDOFF.md) — full context, requirements, architecture, history, status, TODO.
- Deploy: `node scripts/build.mjs` → paste `dist/worker.js` into the Cloudflare dashboard (Persian steps in `docs/GUIDE-FA.md`).
- Local test: `node tools/local-server.mjs` (Node ≥ 22).
