# Splash Screen سه‌بعدی سکه — «دارایی من»

یک سکهٔ سه‌بعدی واقعی (WebGL خام، بدون هیچ کتابخانه) از پایین صفحه پرتاب می‌شود، در هوا حول محور افقی می‌چرخد، روی زمین می‌خورد و می‌نشیند. بعد از برخورد، «دارایی من» کلمه‌به‌کلمه با ماسک از پایین بالا می‌آید و صفحهٔ اصلی با Fade ظاهر می‌شود. دو نسخه دارد: سکهٔ **سفید** (مطابق لوگو) و سکهٔ **طلایی** درخشان.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `coin-splash.js` | موتور انیمیشن (فایل اصلی، حدود ۲۰ کیلوبایت) |
| `coin-face.png` | بافت لوگو که روی سکه می‌افتد (۱۰۲۴×۱۰۲۴) |
| `icon-512.png` | آیکون اصلی، فقط برای حالت جایگزین بدون WebGL |
| `splash-test.html` | صفحهٔ تست مستقل با دکمهٔ «سکه طلایی / سفید» (بدون وابستگی به فایل‌های دیگر) |

## ادغام سریع

۱. فایل‌ها را کنار `index.html` بگذار.

۲. بلافاصله بعد از `<body>`:
```html
<div id="coin-splash" style="position:fixed;inset:0;background:#fff;z-index:99999"></div>
```

۳. آخر `<body>`:
```html
<script src="coin-splash.js"></script>
<script>
  CoinSplash.run({
    face: 'coin-face.png',
    fallback: 'icon-512.png',
    theme: 'gold',          // برای سکهٔ سفید این خط را حذف کن
    onDone: function () {}  // وقتی انیمیشن تمام شد و Fade شروع شد
  });
</script>
```

۴. فونت وزیر (وزن ۹۰۰) را محلی لود کن:
```css
@font-face{font-family:Vazirmatn;font-weight:900;
  src:url(Vazirmatn-Black.woff2) format('woff2');font-display:swap}
```
فایل فونت داخل این بسته نیست و باید آن را از مخزن رسمی Vazirmatn دانلود کنی. اگر فونت نباشد، Splash حداکثر ۰٫۷ ثانیه صبر می‌کند و با Tahoma ادامه می‌دهد.

۵. در `manifest.json`: `background_color` و `theme_color` را `#FFFFFF` بگذار تا Splash سیستمی با انیمیشن یکدست شود.

۶. فایل‌های `coin-splash.js` و `coin-face.png` و `icon-512.png` و فونت را به لیست کش Service Worker اضافه کن تا بدون اینترنت هم کار کند.

## گزینه‌ها (`CoinSplash.run`)

| گزینه | پیش‌فرض | توضیح |
|---|---|---|
| `face` | — | مسیر `coin-face.png` (الزامی) |
| `fallback` | `face` | تصویر جایگزین وقتی WebGL نیست |
| `theme` | سفید | `'gold'` برای سکهٔ طلایی |
| `speed` | `1.25` | سرعت کل انیمیشن (۱ = کندتر، عدد بیشتر = سریع‌تر) |
| `words` | `['دارایی','من']` | کلمه‌های متن، هرکدام جدا ظاهر می‌شوند |
| `bottom` | ۹٪ ارتفاع | فاصلهٔ متن از پایین صفحه (پیکسل) |
| `dx` | `۰٫۱۸ × فونت` | جابه‌جایی افقی متن (پیکسل) |
| `onDone` | — | تابعی که وقتی انیمیشن تمام شد صدا زده می‌شود |

## رفتار

- زمان کل حدود ۳٫۳ ثانیه (حدود ۲٫۴ ثانیه حرکت سکه، بعد مکث کوتاه و Fade).
- با لمس صفحه، انیمیشن رد می‌شود.
- با `prefers-reduced-motion`: فریم نهایی با متن کامل نشان داده می‌شود و اپ باز می‌شود.
- اگر WebGL پشتیبانی نشود یا بافت لود نشود: تصویر ثابت `fallback` نشان داده می‌شود.
- تراکم پیکسل حداکثر ۲ است تا روی گوشی‌های میان‌رده سبک بماند.
- پس‌زمینه همیشه `#FFFFFF` خالص است.

## محدودیت‌ها

- پشت سکه همان لوگوی روی سکه است (طرح جدا ندارد).
- استروک با ضخامت ثابت روی صفحه کشیده می‌شود (یک پاس اضافه روی ناحیهٔ دور سکه). اگر روی گوشی ضعیف افت فریم دیدی، `speed` را کمی کمتر کن یا خبر بده.
- نسخهٔ طلایی در حالت جایگزین بدون WebGL همچنان آیکون سفید را نشان می‌دهد. برای آیکون طلایی، مسیرش را به `fallback` بده.
- انیمیشن را فقط در محیط تست خودم بررسی کردم و اجرای آن روی دستگاه‌های واقعی را باید خودت ببینی.
